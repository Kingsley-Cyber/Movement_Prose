# Implementation decisions

The repository was empty. Initialize one Python package with JSON as the live data authority. Use an isolated environment with pytest and jsonschema; no network or paid services are needed at runtime.

Dimension selections describe tendencies; synchronized slots are named bundles of concurrently usable capabilities. Only the supplied 0.15 slot and 0.20 conditional NULL coefficients are fixed by specification. Other numeric values are versioned authored BLOCK configuration, with mechanical derivations and units recorded rather than empirical claims.

Model calculations use signed pair interactions and a logistic link with unit scale. Conditional relationships remain tactical inferences, not measured probabilities. All scores are uncalibrated.

No source establishes a universal 52 Blocks curriculum or the fictional 52-Dutch and Uno composites. Mechanics attributed to this adaptation are CANON. References to real fighters, gyms and fictional media are visual mnemonics only.

A frozen recovery release supplies known missing records and fields. Live JSON always wins if populated; competing values are reported. Backfill never invents a citation or rewrites tests. Runtime handlers are audited via explicit event mappings.

Geometry is meters in a fixed arena coordinate system, +x left-to-right on screen and +y away from camera. Limb names are anatomical. Output is semantically validated; no IK or physical motion guarantee is claimed.


The original validation suite found three duplicate reciprocal graph records. Their mechanisms and former IDs were merged into the original stable records. It also found feints requested after entering clinch range. The director now earns the feint before the approach and consumes it at execution. The tests were not altered. The second complete evaluation passed.

Coverage warnings disclose weakly non-losing base matrix rows, which still have ties, explicit debts and incoming cross-dimensional counters. They do not justify adding a new model requirement or tuning the supplied fixtures.
